# Compact RSD propagation kernels

Each subdirectory holds the compact inter-layer point-spread-function kernel that
`instantrph/renderer_3d.py` uses to propagate between adjacent MPI layers.

| File | Contents |
|---|---|
| `fullkernel.pt` | `torch.complex64` tensor, layout `[1, C, K, K]` with `C=3` (RGB) and `K=5`. The renderer permutes it to `[C, 1, K, K]` for a depthwise `conv2d(groups=3)`. |

## Directories

- `0.20mm_ksize_2/` — layer spacing 0.20 mm.
- `0.25mm_ksize_2/` — layer spacing 0.25 mm.

The directory name encodes the layer spacing (`<spacing_mm>mm`) that the renderer
matches against the requested `layer_spacing_mm` training/eval setting; `_ksize_2` names
the half-kernel radius (`ksize=2` → a 5×5 kernel).

## Parameters

- Wavelengths: `(660, 520, 450) nm` (`instantrph/constants.py`)
- Pixel pitch: `10.8 µm` (`instantrph/constants.py`)
- Kernel size: `5 × 5` per channel, complex-valued

## Provenance

These are compact Rayleigh–Sommerfeld diffraction (RSD) kernels, precomputed offline for the released layer spacings above and shipped as the paper's compact-RSD-propagator artifact.
They are not regenerated by any script in this repository.
